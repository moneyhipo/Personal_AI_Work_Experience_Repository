## 사용자 규칙 (반드시 지킬 것)
1. 모드가 화면에 띄우는 문구는 **모두 영어**로 씁니다(Nexus 배포용). 사용자와의 대화와 문서는 한국어입니다.
   - **채팅 답변은 항상 한국어로 씁니다.** 중간 보고와 최종 보고도 마찬가지입니다. 영어는 게임 안 UI 문구에만 씁니다. 영어 코드와 문서를 읽은 직후에 답이 영어로 새는 일이 있었습니다.
2. **게임 원본 데이터 파일(`www/data/*.json`, 원본 js)은 수정하지 않습니다.** 모든 변경은 플러그인 코드로 합니다.
3. 판단 근거는 게임 데이터입니다. 위키는 참고만 합니다.
4. 최종 배포판은 "압축 풀고 덮어쓰기"로 설치돼야 합니다.
   - `www/js/main.js` 로더가 모드 플러그인을 덧붙이는 방식입니다(`tools/make_release.js`).
   - `plugins.js`는 배포판에 넣지 않습니다(한글패치와 충돌하기 때문).
5. 커밋과 푸시는 사용자가 요청할 때만 합니다.
6. 요청과 관계없는 코드는 리팩터링하지 않습니다. 플러그인 6개는 서로의 훅 순서에 의존합니다(`mod/plugins_entries.txt` 순서).

## 경로
- 게임: `D:\steam\steamapps\common\Fear & Hunger 2 Termina\`
  - 한글패치가 깔려 있습니다. 데이터 글자만 번역됐고 구조는 원본과 같습니다.
  - 게임 루트에 원본 백업이 있습니다: `www/js/plugins.js.bak_original`, `package.json.bak_original`.
- 디버그 로그: `<게임폴더>\fhcoop_logs\window_<pid>.log`

## 설치, 빌드, 테스트
- 개발용 설치: `node tools/install.js "D:\steam\steamapps\common\Fear & Hunger 2 Termina"` (또는 `tools/install.bat`)
  - 플러그인을 바꿀 때마다 다시 실행합니다.
  - 한글패치가 `plugins.js`를 덮은 뒤에도 다시 실행합니다.
- 자동 테스트(게임 없이 실제 엔진, 플러그인, 데이터를 Node로 실행):
  - `node tools/test/run_tests.js [이름 필터]` — 검사 2614개(0.40 준비 ②). 기본 힙에서 가끔 메모리 부족으로 죽습니다(다시 돌리거나 `--max-old-space-size=6144`). 출력은 파일로 받습니다.
  - `node tools/test/e2e.js` — 70개. 로그가 현재 폴더에 쌓이므로 임시 폴더에서 실행합니다.
  - `node tools/test/e2e_sub.js` — 28개. 이것도 임시 폴더에서 실행합니다.
  - 테스트는 게임 폴더를 `D:\steam\...`, `D:\SteamLibrary\...` 순서로 찾습니다. 다른 곳이면 환경변수 **`FH2_GAME`**에 게임 폴더(`www`가 있는 곳)를 줍니다(`tools/test/harness.js`). 이 PC에서는 사본 `FH2_GAME=D:/git_desk/FH2_dev_game`. (`FH2_DATA`는 `tools/dump.js`·`pr.js` 같은 덤프 스크립트용 `www/data` 경로입니다.)
  - 테스트는 한 번에 하나씩 돌립니다(사용자 PC 메모리).
  - **코드를 바꾸면 세 테스트를 모두 돌리고 결과를 보고합니다.**
- 배포 zip: `node tools/make_release.js <버전>`(버전 필수) → `dist/FH2_Coop_<버전>.zip`. 배포판 README의 제약·버그·접속 안내는 `mod/KNOWN_ISSUES.txt`(영/한)에서 붙습니다.
- Steam 헬퍼(C#):
  - 위치: `tools/steam_helper`. net10.0, Steamworks.NET 2024.8.0, SDK 1.60 `steam_api64.dll`을 씁니다.
  - 빌드: `dotnet publish -c Release -o publish` 후 exe를 `mod/fh_steam_helper/`에 복사합니다.
- 한 PC에서 창 2개로 테스트할 때: 두 번째 창은 `tools/게스트창_실행.bat`으로 띄웁니다.

## 현재 상태 (0.40 준비, 2026-10-22)
- 브랜치 `wip/0.38.3-duel-800hp`. 0.38.3-pre6 이후 "0.40 준비 ①②"가 미커밋입니다. 배포판은 0.38.3-pre6까지 만들었고, 0.40 zip은 사용자가 확인한 뒤 만듭니다.
- **이어서 할 일과 순서는 저장소 `docs/진행상황.md`에 있습니다.** 최신 변경은 `docs/변경기록.md`, 배포 전 검토는 `docs/조사/최종검토_종합.md`(0.40 이후로 미룬 목록 포함), 게임 지식은 `docs/참고/위키_정리.md`, 코드 기준 동작은 `docs/참고/기능별_실제동작.md`.
- 테스트는 run_tests 2614, e2e 70, e2e_sub 28이고 모두 통과했습니다.
- 0.35 이후 기능 대부분은 게임에서 아직 확인하지 않았습니다.
- 큰 기능은 코드 작성 에이전트로 만들고 검수 에이전트로 확인합니다. 검수 때마다 진짜 버그가 나왔습니다.
- 사용자가 게임 중일 때는 Steam 게임 폴더에 설치하지 말고, 테스트는 게임 데이터 사본(`FH2_GAME` 환경변수)으로 돌립니다.
- 0.40 규칙: 시험 결투 `$.TEST_DUEL = false`(테스트에서만 켬), F8 간이 저장은 사용자 결정으로 유지, 최대 4명·같은 이름 한 명, 토너먼트 메뉴 90초.
